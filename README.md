# Series Explorer

## Problem

Finding TV series to watch and keeping track of personal watchlists can be inconvenient.

## Solution

A TV series catalog for discovering shows, exploring their details, and managing watchlists.

- Search, filter, and sort TV series.
- Explore currently airing and top-rated shows.
- Manage watchlists and watched series.
- View detailed information about each show.
- Switch between light and dark themes.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- TVmaze API
- CSS

## Complexity

The main challenges were implementing asynchronous data fetching with caching, organizing reusable components, and managing routing and application state.

## Result

A responsive web application built to practice React and TypeScript through a real API-driven project.

## Getting Started

Requirements: Node.js and npm.

```bash
git clone https://github.com/kolisnykd/series-explorer.git
cd series-explorer
npm install
npm run dev
```

Open the local URL displayed in the terminal.

### Production Build

```bash
npm run build
npm run preview
```
